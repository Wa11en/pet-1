# Личный дневник / Private Diary

Локальный Android-дневник на Kotlin и Compose. minSdk 26; целевая стабильная платформа API 37.

## План реализации

1. Каркас приложения, тема и проверка отсутствия INTERNET в объединённом манифесте.
2. Room + SQLCipher, Android Keystore, PIN/биометрия, интерфейс репозитория и тесты.
3. Локальная модель E5, токенизация, разбиение, индексация и ранжирование.
4. Полный интерфейс дневника, поиск, импорт/экспорт, резервные копии и документация.

Каждый этап завершается `./gradlew assembleDebug testDebugUnitTest` и отдельным коммитом.

## Сборка

JDK 17 или 21, Android SDK 37. Укажите SDK через ANDROID_HOME или local.properties.

```sh
./gradlew assembleDebug testDebugUnitTest
```

Финальная документация дополняется по мере реализации.
