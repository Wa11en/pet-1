# Проверочные APK 1.0.0-rc2

Публичные APK и Android-тесты для передачи в Actions и проверки до публикации. Приватных ключей, дневников и платёжных секретов нет. Исходники: main, commit 734b019. Части ZIP объединяются в порядке manifest.json; все SHA-256 проверяются workflow publish-preview-apks.yml. Это подпись Android Debug для совместимости с прежним тестовым APK, не production-подпись RuStore.
