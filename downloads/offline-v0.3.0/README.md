# Полный офлайн-APK 0.3.0

[Скачать готовый APK](https://github.com/Wa11en/pet-1/releases/download/v0.3.0/Private-Diary-0.3.0-offline.apk).

В архиве находится уже подписанный APK со встроенными E5 int8 и токенизатором. Он разделён на части до 80 МиБ из-за ограничения размера отдельного файла в GitHub. Эти части не нужно открывать на телефоне: используйте ссылку выше.

Для восстановления на компьютере после клонирования репозитория:

```sh
python3 scripts/restore_offline_apk.py downloads/offline-v0.3.0 /tmp/private-diary-offline
```

Укажите новую пустую папку назначения. Скрипт проверит SHA-256 каждой части, архива, APK и обеих моделей, затем сохранит `Private-Diary-0.3.0-offline.apk`. Android SDK и ключ подписи для восстановления не нужны. GitHub Actions использует ту же проверку перед публикацией файла в релизе.
