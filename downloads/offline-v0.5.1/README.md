# Офлайн-сборка 0.5.1

[Скачать APK](https://github.com/Wa11en/pet-1/releases/download/v0.5.1/Private-Diary-0.5.1-offline.apk).

Для восстановления подписанного APK после клонирования репозитория:

```sh
python3 scripts/restore_offline_apk.py downloads/offline-v0.5.1 /tmp/private-diary-051 --version 0.5.1
```

Папка назначения должна быть новой. Проверяются SHA-256 частей, ZIP, APK и модели. На телефоне используйте APK по ссылке выше.

`android-test/search-input-tests.apk` предназначен только для автоматического Android-теста, не для установки пользователем. Runner подписан тем же сертификатом, проверяется отдельной контрольной суммой и не попадает в Assets релиза. CI устанавливает настоящий APK 0.5.0, проверяет ожидаемое падение и затем прогоняет три теста на APK 0.5.1. Ключ подписи не передаётся.

APK: 240 822 073 байта, около 241 МБ. SHA-256: `17c38d0fe5c6a466e9c7af2a2756bf9642a6514579731d317c42c8e1036865c2`.
