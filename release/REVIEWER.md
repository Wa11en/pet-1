# Инструкция для проверки Private Diary / «Личный дневник»

Этот документ можно передать модерации с бесплатной `store`-сборкой. Он не содержит пользовательских данных, секретов подписи, кода восстановления Pro или универсального PIN. Настоящий приём оплаты и реклама пока не настроены: без production-параметров приложение сообщает о недоступности интеграций, основные функции доступны.

## Монетизация и доступ

Установка и базовые функции бесплатны. Реклама Яндекса открывается только по действию пользователя с отдельным пояснением о сети и данных. Отказ или отсутствие рекламы не блокируют дневник. Pro за **99 ₽ за календарный месяц** отключает рекламу и открывает локальную статистику настроения, тегов и регулярности записей.

Оплата выполняется через собственный HTTPS-сервер и форму YooKassa СБП, независимо от платёжных сервисов размещения приложения. Каждое продление оплачивается отдельно; автосписаний нет. Владелец должен предоставить модерации рабочее тестовое окружение/доступ и раскрыть стороннюю оплату в анкете RuStore. Демонстрационная активация через локальный флаг не заменяет тестирование платежа.

## Первый запуск

1. Установите чистую `store`-сборку на Android 8.0 или новее. Интернет требуется магазину для установки, рекламе и явным действиям оплаты/восстановления Pro; дневнику он не нужен.
2. Прочитайте локальную политику и **создайте собственный PIN из 6–12 цифр**. Для бесплатного дневника не нужны удалённая регистрация, телефон и почта.
3. Биометрия необязательна; без подходящего датчика используется PIN. Запомните PIN: разработчик не может его восстановить. Очистка данных тестовой установки удалит записи и локальные ключи.
4. Используйте вымышленные записи. Универсального PIN, скрытого аккаунта и обхода блокировки нет.

## Бесплатные сценарии — в том числе в авиарежиме

| Проверка | Действия и ожидаемое поведение |
| --- | --- |
| Запись | Создать запись, раскрыть «Дополнительно», выбрать настроение и теги, сохранить. Запись появляется в журнале. |
| Черновик | Начать новую запись, переместить курсор, выйти назад. Продолжение черновика возвращает текст и курсор. Задержка автосохранения — 400 мс, выход/сворачивание запускает сохранение. |
| Слова | Сохранить `поиграл в контру` и `выиграл в доту`. Запрос `игра` в режиме «По словам» находит совпадения внутри слов. Проверить первую/вторую букву и быстрый ввод. |
| Смысл | Создать `поел пиццу` и отдельную игровую запись; дождаться подготовки поиска. Попробовать `еда`. Модель встроена; поиск приближённый, число близости не является вероятностью или процентом. |
| Фильтры | Выбрать даты, настроение и тег. Проверить оба режима, пустой запрос с фильтрами, открытие найденного фрагмента в редакторе. |
| Календарь/избранное | Выбрать день в календаре, проверить точки записей и «Все записи». Поставить звезду, включить «Избранное». |
| Корзина | Удалить запись, нажать «Отменить». Повторно удалить, открыть корзину, восстановить/окончательно удалить с подтверждением. Срок — 30×24 часа. |
| Импорт/Markdown | Импортировать UTF-8 TXT/MD через системный выбор. Markdown ZIP содержит открытый текст; экспорт только по действию пользователя. Файловый провайдер может быть облачным. |
| Зашифрованная копия | Создать `.pdiary` с паролем от 10 символов и восстановить. Неверный пароль не меняет записи. Черновики/корзина не входят в копию; избранное сохраняется. |
| Блокировка | Свернуть приложение дольше таймаута, вернуться: нужен PIN. При блокировке скрываются записи, результаты и статистика. |
| Напоминания | По умолчанию выключены. На Android 13+ проверить разрешение/отказ, общее уведомление без содержимого. Android может задерживать неточные будильники. |
| Язык/тема | Русский/английский, светлая/тёмная тема, крупный шрифт и экранная клавиатура. |
| Отсутствие сети | В авиарежиме создать и найти запись, импортировать/экспортировать локальный файл, открыть копию, заблокировать приложение. Покупка и реклама не должны мешать этим функциям. |

## Реклама — при подключённом собственном блоке

1. Без Pro открыть просмотр рекламы. До согласия не должно быть инициализации SDK или загрузки объявления. Прочитать пояснение: Яндекс получает IP и технические данные, дневник не прикладывается к запросу.
2. Отказаться: вернуться к дневнику без ограничения функций. Повторить без сети — ошибка рекламы также не закрывает дневник.
3. Согласиться и проверить показ. После закрытия и ухода рекламы в фон отдельный рекламный процесс должен завершаться. Переход к банковскому/внешнему приложению не должен раскрывать записи.
4. При действующем Pro реклама не предлагается. Снимки дневника остаются защищены `FLAG_SECURE`.

## Pro и оплата СБП — в тестовом окружении владельца

1. Открыть Pro: видны цена 99 ₽/месяц, состав доступа, ручное продление и отсутствие автосписаний. Бесплатные функции остаются доступны без покупки.
2. Начать оплату: открывается HTTPS-форма YooKassa/СБП. Отмена, потеря сети и один лишь возврат из браузера не должны активировать Pro.
3. Выполнить успешный тестовый СБП и нажать проверку статуса. Сервер подтверждает платёж у провайдера, приложение проверяет подпись лицензии, показывает дату окончания. Повторная проверка того же платежа не добавляет ещё месяц и не создаёт второе списание.
4. В авиарежиме открыть статистику: настроение, число записей/дней, серии и теги рассчитываются локально. Даты — по часовому поясу устройства, среднее учитывает только выбранное настроение, черновики/корзина не учитываются. Диагнозов и анализа содержания текста нет.
5. Проверить ручную повторную оплату, восстановление доступа по сохранённому секретному коду и границы месяца. Код не публиковать; восстановление Pro не переносит сам дневник.
6. В тестовом окружении дождаться конца/выдать короткий тестовый срок: статистика закрывается, бесплатные записи, поиск и копии доступны. Рабочий срок Pro не должен зависеть от возврата приложения из браузера.

Подписанный доступ работает офлайн до выданного срока по часам устройства. Мгновенный отзыв возврата платежа без сети и защита от изменения времени не гарантируются; проверять ограничения честно, не считать локальный PIN подтверждением оплаты. В production запрещены тестовый ключ провайдера и выдача доступа без подтверждённого платежа.

## Особенности

- Первоначальная индексация выполняется локально; новая запись появляется в смысловом поиске после обработки. Поиск может ошибаться.
- В `store` есть INTERNET для рекламы и оплаты. Базовые данные дневника не отправляются на сервер. Отдельная `offline`-сборка без разрешения и SDK выпускается отдельно и не является артефактом этого коммерческого сценария.
- PIN, пароль копии и утерянные записи разработчик восстановить не может. Удаление приложения удаляет локальную базу и Keystore. Облачного восстановления дневника нет.
- `FLAG_SECURE` блокирует обычные скриншоты, запись экрана и превью. Для материалов магазина используется отдельный debug-only экран с синтетическими записями, отсутствующий в релизе.

Поддержка: `gr1val@yandex.ru`. Для отчёта достаточно версии, модели телефона, Android и синтетического примера. Не отправляйте записи, PIN, файлы копий, пароль, код Pro или ключ подписи.
