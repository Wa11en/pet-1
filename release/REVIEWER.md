# Инструкция для проверки Private Diary / «Личный дневник»

Этот документ можно передать модерации вместе с релизной сборкой. Он не содержит данных пользователей, секретов подписи или универсального кода разблокировки.

## Получение платной сборки

Приложение планируется как разовая покупка до установки. В нём нет отдельного экрана оплаты, подписок, внутренних покупок и платёжного SDK. Доступ к установке для проверки владелец предоставляет через предусмотренные RuStore тестовые средства/токены. Эти данные не выдумываются и не помещаются в приложение или публичный репозиторий.

Текущая подготовка не означает, что платное размещение одобрено магазином. До подачи нужно подтвердить право аккаунта продавца на монетизацию и заполнить сведения владельца/цену.

## Первый запуск и доступ

1. Установите чистую релизную сборку на Android 8.0 или новее. Для покупки и установки магазин может использовать интернет; установленный дневник работает без него.
2. На первом запуске прочитайте пояснение о приватности и **создайте собственный PIN из 6–12 цифр**. Никакой регистрации на сервере, телефона, почты, платёжных реквизитов или заранее выданного логина внутри дневника нет.
3. Биометрию можно не включать. На устройстве без подходящего датчика используется PIN.
4. Запомните выбранный PIN для следующих запусков. При забытом PIN встроенного сброса нет; для повторной проверки с пустыми данными можно очистить данные тестовой установки, учитывая, что это удалит записи.

Универсального PIN, скрытого аккаунта и обхода блокировки нет. Рекомендуем проверять на синтетических записях, не добавляя личные сведения.

## Основные сценарии

| Проверка | Действия и ожидаемое поведение |
| --- | --- |
| Запись | Создать запись, ввести несколько предложений, раскрыть «Дополнительно», выбрать настроение и теги. Сохранить; запись появляется в журнале. |
| Черновик | Начать новую запись, поставить курсор в середину, выйти назад. Карточка продолжения черновика возвращает текст и курсор. Через 400 мс после ввода черновик записывается в зашифрованную базу; выход/сворачивание запускает немедленное сохранение. |
| Слова | Сохранить `поиграл в контру` и `выиграл в доту`. В режиме «По словам» запрос `игра` находит совпадения внутри слов. Проверить ввод первой/второй буквы и быстрые изменения строки. |
| Смысл | Создать `поел пиццу` и отдельную игровую запись; дождаться окончания подготовки поиска. В режиме «По смыслу» попробовать `еда`. Модель включена в сборку. Поиск приближённый, исходное число близости не является вероятностью и не показывается как процент совпадения. |
| Фильтры | В поиске раскрыть фильтры и выбрать даты, настроение, тег. Условия сочетаются; с пустым запросом показываются записи, подходящие по фильтрам. Открытие результата прокручивает редактор к найденному фрагменту, если он есть в текущем тексте. |
| Календарь и избранное | Выбрать день в календаре, проверить точки дней с записями и переключатель «Все записи». Поставить звезду на карточке и включить «Избранное». |
| Корзина | Удалить сохранённую запись, нажать «Отменить». Повторно удалить и открыть Настройки → Корзина. Удалённые записи не появляются в активном поиске; можно восстановить или окончательно удалить с подтверждением. Срок восстановления — 30×24 часа. |
| Импорт/Markdown | Через системный файловый выбор импортировать отдельный UTF-8 TXT/MD. Экспорт Markdown создаёт ZIP открытого текста и требует явного действия пользователя. Системный провайдер, выбранный пользователем, может быть облачным. |
| Зашифрованная копия | Создать `.pdiary` с паролем не короче 10 символов, сохранить файл через системный выбор, восстановить копию. Неверный пароль не должен заменять записи. Новые копии сохраняют избранное; поддерживается чтение старого формата v1. |
| Локальная блокировка | В настройках выбрать таймаут. Свернуть приложение дольше таймаута, вернуться: показывается PIN. При блокировке текст и результаты скрываются. |
| Напоминания | По умолчанию выключены. Включить выбранное напоминание, на Android 13+ предоставить или отклонить уведомления. При отказе переключатель остаётся выключенным. Выбрать время; уведомление содержит только общий текст. Android может задерживать неточные будильники. |
| Язык и тема | Переключить русский/английский в настройках, светлую/тёмную тему системы. Проверить крупный системный шрифт и экранную клавиатуру. |
| Работа офлайн | После установки включить авиарежим. Создание записей, блокировка и оба режима поиска должны работать; обработка записей не требует обращения к серверу. |

## Предусмотренное поведение

- При первом открытии дневник готовит локальный индекс. Новая/изменённая запись участвует в смысловом поиске после обработки; интерфейс показывает индексацию.
- Из модели получается приближённый поиск, а не безошибочное понимание любого текста. Результаты и порядок зависят от содержания и языка.
- Снимки экрана и обычная запись экрана блокируются `FLAG_SECURE`; превью в недавних приложениях скрыто. Это ожидаемая защита, а не ошибка рендеринга. Для отчёта используйте описание действий и вымышленные примеры.
- Локальная модель увеличивает размер приложения и требует памяти/свободного места. Скорость зависит от устройства.
- Android Keystore защищает ключ базы на конкретной установке. PIN и пароль резервной копии не восстанавливаются разработчиком. Облачной синхронизации и удалённого восстановления нет.
- Резервная копия содержит сохранённые активные записи. Черновики и корзина в экспорт не входят; восстановление копии заменяет записи и очищает эти локальные состояния. Поисковый индекс строится заново.
- Приложение не имеет разрешения INTERNET и не содержит рекламы, аналитики, удалённых аккаунтов или сетевой проверки покупки. PIN является защитой записей, а не DRM.
