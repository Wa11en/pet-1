# Проверка кандидата 1.0.0-rc2

22 ноября 2026 года, versionCode 10. Это сборки для тестирования с прежней подписью Android Debug, не production-релиз RuStore. Настройки платёжного сервера, публичного ключа Pro и рекламного блока пустые: настоящих платежей, рекламных запросов и тестовой разблокировки Pro нет.

- `./gradlew assembleDebug testDebugUnitTest assembleOfflineDebugAndroidTest assembleStoreDebugAndroidTest lintOfflineDebug lintStoreDebug --max-workers=2`: успешно для обоих вариантов. Offline: 179 тестов, 1 пропуск; Store: 187 тестов, 1 пропуск; ошибок нет, lint без ошибок. Пропущен опциональный JVM-тест ONNX без `-PverifyOfflineModel=true`; в CI он включён.
- `PYTHONPATH=backend python3 -m unittest discover -s backend/tests`: 53 теста, успешно, провайдер подменяется только внутри тестов. Денежных операций не выполнялось.
- `python3 -m unittest discover -s scripts/tests`: 64 теста, успешно, включая упаковку материалов и проверку реальных настроек из DEX.
- `python3 scripts/test_render_privacy.py`: 8 тестов; обе `render_privacy.py --check` / `--variant store --check` успешны.
- Проверены подписи APK, версия, SHA-256 встроенных модели/токенизатора, оба объединённых манифеста и определения классов DEX. В offline запрещены INTERNET и сетевые SDK. Store имеет INTERNET и строго заданные рекламные компоненты в `:ads`; их автоматический запуск отключён.
- Транзитивные зависимости рекламы включают AppMetrica, OkHttp, помощник Advertising ID и три базовых класса исключений Firebase из Play Services. Это не Firebase Analytics/Crashlytics. Рекламные запросы не содержат данные дневника; сам SDK передаёт технические сведения. Нужен отдельный аудит трафика с рабочим рекламным блоком на телефоне.
- Точные опубликованные APK прошли **21 offline / 22 store Android-теста**: [прогон 45025676747](https://github.com/Wa11en/pet-1/actions/runs/45025676747). Сверены SHA-256 и прежний сертификат подписи; ключ в CI не передавался. Проверяется также отсутствие процесса рекламы при пустом ID блока.

Манифест явно выключает optional preload-provider AppMetrica даже при отсутствии его реализации в текущем SDK. Включение блокируют Gradle guard и инструментальный тест. Два других компонента SDK поставляются runtime-зависимостями: их наличие в установленном APK проверяется загрузкой класса без инициализации. Только у этих трёх узлов манифеста отключено ложное срабатывание MissingClass; остальные проверки действуют.

Полный [source/release прогон 45040712018](https://github.com/Wa11en/pet-1/actions/runs/45040712018), исходники `a220f1182bf01b97e122750eb4957a05ac76796e`, завершён успешно: 175 offline / 183 store unit-теста без пропусков, включая реальную ONNX; lint без ошибок; проверены unsigned APK/AAB, модель и 16-КБ выравнивание; на неотладочных релизных копиях прошли 21 / 22 Android-теста. Получены восемь PNG настоящего Compose-интерфейса с вымышленными записями. Происхождение и SHA-256 — в [provenance.json](store/screenshots/provenance.json). Более поздние изменения добавляют ссылки на условия оплаты и проверку конфигурации APK; их локальные проверки приведены выше. Эти результаты не заменяют проверку рекламы/СБП с подключёнными провайдерами.

До отправки в магазин остаются реальные аккаунты провайдеров, HTTPS-размещение сервера/политики, чеки НПД, юридические данные, декларации RuStore, физический тест сетевого поведения и собственный production-ключ подписи. Пустые настройки не дают готовность публикации: `scripts/check_release_readiness.py --report-only` перечисляет незаполненные пункты.
