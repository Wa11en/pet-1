Релизный код **Private Diary 1.0.0 (11)** собран с отключённой отладкой и встроенной моделью поиска. APK, шифрование и поиск проверены на Android. Пакет также проверяет создание и повторное использование ключа в Windows PowerShell 5.1.

Этот ZIP содержит готовый **неподписанный релизный APK** и инструменты локальной подписи. Постоянный ключ создаётся на вашем компьютере и остаётся у вас; в архиве нет ключа или пароля.

На Windows:

1. Установите [Temurin 21 JDK](https://adoptium.net/temurin/releases/?version=21&os=windows&package=jdk), если Java ещё нет.
2. Распакуйте весь ZIP и откройте `Sign-Windows.cmd`.
3. Придумайте и подтвердите пароль ключа. Сохраните пароль отдельно от резервных копий ключа.
4. В RuStore загрузите созданный **`output/Private-Diary-1.0.0-RuStore.apk`**.

Для macOS/Linux в архиве есть `sign-release.sh` и русская инструкция. Android Studio не нужна. Исходный файл с `unsigned` в имени в RuStore не загружайте.

В этой версии работает бесплатный офлайн-дневник. Реклама и СБП пока не подключены, их неактивные кнопки скрыты. Подготовленные интеграции сохранены для последующего подключения; подписка сейчас не продаётся.

Перед установкой APK с новой подписью сохраните записи из прежнего тестового приложения в зашифрованную `.pdiary`-копию. Удаление приложения удаляет его локальные данные. Ключ владельца понадобится для всех обновлений; не публикуйте `.p12` или пароль.

Подпись APK не означает отправку в магазин или одобрение модерацией. Реквизиты, публичная политика и анкета RuStore заполняются владельцем перед отправкой.
