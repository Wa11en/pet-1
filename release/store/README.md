# Тексты для RuStore

Все `.txt` — UTF-8, без служебных заголовков и разметки: содержимое можно целиком вставлять в соответствующее поле. Для карточки используется один комплект. Не объединяйте описание текущей проверочной версии с описанием будущего выпуска.

## Какой комплект брать

| Сценарий | RU | EN | Статус |
| --- | --- | --- | --- |
| Будущий бесплатный выпуск с рекламой и Pro | [ru/](ru/) | [en/](en/) | Подготовленный текст для публикации **после подключения и проверки монетизации** |
| Текущая проверочная версия 1.0.0-rc2 | [current-preview/ru/](current-preview/ru/) | [current-preview/en/](current-preview/en/) | Прямо сообщает, что реклама и оплата Pro недоступны |

`metadata-ru.json` и `metadata-en.json` соответствуют **будущему выпуску**: `displayName`, `shortDescription` и `fullDescription` дословно совпадают с `.txt` в `ru/` и `en/`, за исключением завершающего перевода строки в файле. Эти JSON не описывают доступность рекламы и платежей в текущем APK. В них сохранён `submissionReady: false`.

## Что находится в каждом комплекте

| Файл | Куда использовать |
| --- | --- |
| `name.txt` | Название приложения |
| `short-description.txt` | Краткое описание |
| `full-description.txt` | Полное описание |
| `release-notes.txt` | Что нового; для будущего выпуска — первый выпуск в RuStore, для preview — 1.0.0-rc2 |
| `screenshot-captions.txt` | Заголовки и подписи четырёх снимков: журнал, редактор, поиск по словам, календарь |
| `help-faq.txt` | Справка и ответы поддержки; это отдельный материал, а не продолжение поля полного описания |
| `support-template.txt` | Шаблон обращения пользователя и первого ответа поддержки; не вставлять в карточку приложения |

Подписи соответствуют возможностям показанных экранов. Экран поиска в наборе открыт в режиме «По словам»: подпись не выдаёт его за пример смыслового поиска. Не добавляйте изображения экранов оплаты или рекламы как работающих функций до проверки реального подключения. Для снимков используйте только вымышленные записи. Иконка и обложки описаны в [assets/README.md](assets/README.md); они не заменяют снимки интерфейса.

## Блокировки будущего выпуска

Сейчас идентификатор рекламы, адрес платёжного сервера и публичный ключ лицензии не настроены. Реклама и приём оплаты в текущем preview недоступны. Подготовленный комплект `ru/` / `en/` с утверждениями о рекламе и Pro нельзя использовать для этой версии.

Перед использованием будущего комплекта владелец закрывает требования из [RUSTORE.md](../RUSTORE.md) и [release-config.json](../release-config.json): реальные подключения рекламы, HTTPS-сервера, YooKassa, СБП и чеков; проверка бесплатных функций, согласия на рекламу и настоящего сценария оплаты/восстановления; документы и доступная публичная политика; раскрытие сторонней оплаты и рекламы; собственная релизная подпись; проверенные материалы и требования RuStore. Настройка одного JSON ничего не подключает.

Имя владельца для юридических полей не предоставлено. Нельзя подставлять вместо него бренд Private Diary, придумывать ИП или компанию. Возрастную категорию определяют по анкете и фактическому содержимому; официальная категория в комплекте не назначена. Почта поддержки: `gr1val@yandex.ru`. Текущий адрес политики в метаданных — `https://wa11en.github.io/pet-1/privacy/store/`; доступность без входа и соответствие итоговой сборке проверяются перед отправкой.

## Проверенные ограничения текста

| Поле | Ограничение комплекта | RU | EN |
| --- | --- | --- | --- |
| Название | до 30 знаков | 14 | 13 |
| Краткое описание | до 80 знаков | 73 | 80 |
| Полное описание будущего выпуска | до 4000 знаков | 2907 | 2792 |
| Что нового для будущего выпуска | до 500 знаков | 419 | 400 |

Знаки считаются как символы Unicode, включая пробелы и внутренние переводы строк, без последнего перевода строки в `.txt`. На момент подготовки поля JSON и `.txt` сверены, структура двух языков совпадает, все JSON разбираются. После любых правок повторите проверку длины и сверку метаданных.

Тексты учитывают ограничения продукта: смысловой поиск приближённый; PIN и пароль копии не восстанавливаются; удаление приложения стирает локальные записи; черновики и корзина исключены из копий; Markdown открыт; выбранный файловый сервис может быть облачным. Для `store` нет обещаний об отсутствии INTERNET или любой телеметрии. Поддержка не запрашивает записи, копии, PIN, пароли, код восстановления Pro и банковские реквизиты.
