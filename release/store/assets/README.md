# Графика магазина

Готовые файлы для страницы приложения:

| Файл | Размер | Назначение |
| --- | --- | --- |
| `icon-512.png` | 512×512, 32-битный PNG (RGBA) | Иконка магазина с непрозрачным квадратным фоном |
| `feature-ru.png` | 1024×500, PNG RGB без альфа-канала | Основное изображение на русском |
| `feature-en.png` | 1024×500, PNG RGB без альфа-канала | Основное изображение на английском |

Иллюстрация взята из реальной векторной иконки `app/src/main/res/drawable/ic_diary.xml`; цвета соответствуют бумажной теме приложения. Рамку и маску иконки накладывает магазин. Цен, рекламных значков, отзывов и обещаний безошибочного поиска на изображениях нет.

Это обложки и иконка, **не скриншоты интерфейса**. Для секции скриншотов нужны отдельные снимки актуального приложения с вымышленными записями; защиту `FLAG_SECURE` пользовательской сборки отключать не требуется.

Альтернативные описания:

- RU: «Бумажный дневник с закладкой на мягком зелёном фоне. Поиск по смыслу на устройстве, без рекламы и аккаунта».
- EN: “A paper diary with a bookmark on a soft green background. Search by meaning on your device, without ads or an account.”

Воспроизведение из корня проекта:

```sh
python3 scripts/render_store_artwork.py
```

Нужны Python 3, Pillow, Inkscape и установленные свободные шрифты Noto Sans / Noto Serif с кириллицей. Скрипт не скачивает ресурсы и не обращается к текстам дневника. Шрифты в репозиторий не копируются. Исходные SVG сохранены рядом с PNG; для точного переноса готовых файлов используйте опубликованные `SHA256SUMS-artwork.txt`.
